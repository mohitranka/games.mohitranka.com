      About Clutch

      Four original, short arcade sports challenges. These are simplified sports games, with personal bests saved on this device and no public leaderboard. The same game code is packaged for standalone web and Reddit. Clutch is a working prototype name.

      Keyboard: choose a sport and press Play, then use Space for the main action. In basketball, hold and release Space. In tennis, use the left and right arrow keys or the aim slider. In soccer, left and right aim across the goal and up and down set the height; the Aim and Height sliders do the same. Escape pauses the game. On touch screens, use the action button and sliders, or tap the goal in soccer to pick a spot.

      These games include visual timing and aiming challenges. They do not yet offer equivalent nonvisual gameplay.
